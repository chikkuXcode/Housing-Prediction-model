# Housing Price Prediction

A machine learning based housing price prediction system built using FastAPI and HTML, CSS, JavaScript.

## Features

- Housing price prediction
- Location based prediction
- 2022-2026 price projection
- Nearby hospitals
- Nearby schools
- Nearby malls
- Nearby police stations
- Distance calculation
- Map links

## Tech Stack

### Backend
- Python
- FastAPI
- Scikit-learn
- Pandas

### Frontend
- HTML
- CSS
- JavaScript

### APIs
- OpenStreetMap Nominatim
- OpenStreetMap Overpass
